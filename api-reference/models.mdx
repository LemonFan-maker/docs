## `GET /v1/models`

获取当前 API Key 可用的所有模型。

### 请求头

| 头字段 | 值 |
|--------|-----|
| `Authorization` | `Bearer sk-你的密钥` |

### 响应格式

```json
{
  "data": [
    {
      "id": "gpt-5.4",
      "type": "model",
      "display_name": "gpt-5.4",
      "created_at": "2024-01-01T00:00:00Z"
    },
    {
      "id": "gpt-5.5",
      "type": "model",
      "display_name": "gpt-5.5",
      "created_at": "2024-01-01T00:00:00Z"
    }
  ],
  "object": "list"
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | array | 模型列表 |
| `data[].id` | string | 模型 ID，调用时使用此值 |
| `data[].type` | string | 固定为 `"model"` |
| `data[].display_name` | string | 模型显示名称 |
| `data[].created_at` | string | 创建时间 |
| `object` | string | 固定为 `"list"` |

### 使用示例

```bash
curl https://sub.orionisli.cn/v1/models \
  -H "Authorization: Bearer sk-你的密钥" | jq '.data[].id'
```

<Note>
  不同套餐的 API Key 返回的模型列表不同。GPT 套餐返回 GPT 系列模型，Claude 套餐返回 Claude 系列模型。
</Note>
