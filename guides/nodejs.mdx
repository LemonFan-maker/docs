## OpenAI SDK

适用于 GPT 系列模型。

### 安装

```bash
npm install openai
```

### 基本使用

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-你的密钥",
  baseURL: "https://sub.orionisli.cn/v1",
});

const response = await client.chat.completions.create({
  model: "gpt-5.4",
  messages: [
    { role: "system", content: "你是一个有帮助的助手。" },
    { role: "user", content: "请用 JavaScript 写一个斐波那契函数" },
  ],
});

console.log(response.choices[0].message.content);
```

### 流式输出

```javascript
const stream = await client.chat.completions.create({
  model: "gpt-5.4",
  messages: [{ role: "user", content: "讲一个故事" }],
  stream: true,
});

for await (const chunk of stream) {
  const content = chunk.choices[0]?.delta?.content;
  if (content) process.stdout.write(content);
}
```

### 多轮对话

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-你的密钥",
  baseURL: "https://sub.orionisli.cn/v1",
});

const messages = [
  { role: "system", content: "你是一个有帮助的助手。" },
];

// 模拟对话
messages.push({ role: "user", content: "什么是闭包？" });

const response = await client.chat.completions.create({
  model: "gpt-5.4",
  messages,
});

const reply = response.choices[0].message.content;
messages.push({ role: "assistant", content: reply });
console.log(reply);

// 继续对话
messages.push({ role: "user", content: "能给个例子吗？" });

const response2 = await client.chat.completions.create({
  model: "gpt-5.4",
  messages,
});

console.log(response2.choices[0].message.content);
```

### 函数调用（Function Calling）

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-你的密钥",
  baseURL: "https://sub.orionisli.cn/v1",
});

const tools = [
  {
    type: "function",
    function: {
      name: "get_weather",
      description: "获取指定城市的天气",
      parameters: {
        type: "object",
        properties: {
          city: { type: "string", description: "城市名称" },
        },
        required: ["city"],
      },
    },
  },
];

const response = await client.chat.completions.create({
  model: "gpt-5.4",
  messages: [{ role: "user", content: "北京天气怎么样？" }],
  tools,
  tool_choice: "auto",
});

const message = response.choices[0].message;
if (message.tool_calls) {
  const toolCall = message.tool_calls[0];
  console.log(`调用函数: ${toolCall.function.name}`);
  console.log(`参数: ${toolCall.function.arguments}`);
}
```

## Anthropic SDK

适用于 Claude 系列模型。

### 安装

```bash
npm install @anthropic-ai/sdk
```

### 基本使用

```javascript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "sk-你的密钥",
  baseURL: "https://sub.orionisli.cn",
});

const message = await client.messages.create({
  model: "claude-sonnet-4-6",
  max_tokens: 1024,
  messages: [
    { role: "user", content: "请用 JavaScript 写一个斐波那契函数" },
  ],
});

console.log(message.content[0].text);
```

### 带系统提示词

```javascript
const message = await client.messages.create({
  model: "claude-sonnet-4-6",
  max_tokens: 1024,
  system: "你是一个资深前端开发者，回答要简洁专业。",
  messages: [{ role: "user", content: "React 中 useEffect 和 useLayoutEffect 的区别？" }],
});
```

### 流式输出

```javascript
const stream = client.messages.stream({
  model: "claude-sonnet-4-6",
  max_tokens: 1024,
  messages: [{ role: "user", content: "讲一个故事" }],
});

for await (const event of stream) {
  if (event.type === "content_block_delta") {
    process.stdout.write(event.delta.text);
  }
}
```

## 使用 fetch 直接调用

不安装 SDK，直接使用 Node.js 内置的 fetch。

```javascript
const response = await fetch(
  "https://sub.orionisli.cn/v1/chat/completions",
  {
    method: "POST",
    headers: {
      Authorization: "Bearer sk-你的密钥",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "gpt-5.4",
      messages: [{ role: "user", content: "你好" }],
    }),
  }
);

const data = await response.json();
console.log(data.choices[0].message.content);
```

<Note>
  Node.js 18+ 内置了 `fetch`。如果使用更低版本，请安装 `node-fetch`。
</Note>

## 使用 dotenv 管理密钥

```bash
npm install dotenv
```

创建 `.env` 文件：

```
OPENAI_API_KEY=sk-你的密钥
OPENAI_BASE_URL=https://sub.orionisli.cn/v1
```

```javascript
import "dotenv/config";
import OpenAI from "openai";

const client = new OpenAI(); // 自动读取环境变量
```

<Warning>
  将 `.env` 添加到 `.gitignore`，避免密钥泄露。
</Warning>
