## API 基础信息

| 项目 | 值 |
|------|-----|
| API Base URL | `https://sub.orionisli.cn` |
| 认证方式 | Bearer Token（`Authorization: Bearer sk-xxx`） |
| OpenAI 端点 | `POST /v1/chat/completions` |
| Claude 端点 | `POST /v1/messages` |
| 模型列表 | `GET /v1/models` |

## 快速开始

<Steps>
  <Step title="注册账号">
    前往 [控制台](https://sub.orionisli.cn) 注册账号
  </Step>
  <Step title="获取 API Key">
    在控制台中创建并复制你的 API Key（`sk-` 前缀）
  </Step>
  <Step title="发送第一个请求">
    ```bash
    curl https://sub.orionisli.cn/v1/chat/completions \
      -H "Authorization: Bearer sk-你的密钥" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-5.4",
        "messages": [{"role": "user", "content": "你好！"}]
      }'
    ```
  </Step>
</Steps>

## 推荐：CC Switch 一键配置

如果你使用 Claude Code、Codex、OpenClaw 等编程工具，推荐使用 **CC Switch** 一键配置 API 端点：

```bash
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

安装后在图形界面中添加 OrionisLi provider，所有工具自动生效。详见 [CC Switch 文档](/tools/cc-switch)。
