## 查看可用模型

通过 API 获取你当前 Key 可用的模型列表：

```bash
curl https://sub.orionisli.cn/v1/models \
  -H "Authorization: Bearer sk-你的密钥"
```

<Note>
  不同套餐的 API Key 可用的模型不同。以下列表为所有可能支持的模型。
</Note>

## 模型选择建议

### 按场景选择

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| 日常对话 | `gpt-5.4` 或 `claude-sonnet-4-6` | 性价比高，速度快 |
| 复杂推理 | `gpt-5.5` 或 `claude-opus-4-7` | 最强推理能力 |
| 代码生成 | `gpt-5.3-codex` 或 `claude-sonnet-4-6` | 代码理解能力强 |
| 快速响应 | `gpt-5.4-mini` 或 `claude-haiku-4-5` | 延迟低，成本低 |
| 图像生成 | `gpt-image-2` | 最新图像生成模型 |
| 长文写作 | `claude-opus-4-7` | 长上下文，输出质量高 |

### 按成本选择

<Note>
  成本从低到高排列。具体价格请参考[价格说明](/pricing)。
</Note>

1. **低成本**：`gpt-5.4-mini`、`claude-haiku-4-5`
2. **中等**：`gpt-5.4`、`claude-sonnet-4-6`
3. **高性能**：`gpt-5.5`、`claude-opus-4-7`

## 兼容性说明

- 所有 GPT 模型通过 **OpenAI 协议**（`/v1/chat/completions`）调用
- 所有 Claude 模型通过 **Claude 协议**（`/v1/messages`）调用
- 模型 ID 区分大小写，请使用上表中的精确 ID
- 不同套餐的 Key 可用模型范围不同，请在控制台确认
