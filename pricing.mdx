## 计费方式

OrionisLi API 按实际 token 使用量计费，用多少付多少。

### 什么是 Token

Token 是 AI 模型处理文本的基本单位。大致换算关系：

- 1 个英文单词 ≈ 1 token
- 1 个中文字 ≈ 1.5-2 tokens
- 1000 tokens ≈ 750 个英文单词 ≈ 500 个中文字

### 计费项目

- **输入 token**（Prompt）：你发送给模型的文本
- **输出 token**（Completion）：模型生成的回复

输入和输出的价格通常不同，输出价格一般高于输入价格。

### 如何查看 Token 用量

每次 API 调用的响应中都包含 `usage` 字段，显示本次请求的 token 消耗：

```json
{
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 50,
    "total_tokens": 62
  }
}
```
