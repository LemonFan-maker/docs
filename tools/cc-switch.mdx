## 什么是 CC Switch

CC Switch 是一个跨平台桌面工具，统一管理以下 AI 编程 CLI 工具的 API 配置：

- **Claude Code**
- **Codex**
- **OpenCode**
- **OpenClaw**
- **Gemini CLI**

你不需要手动编辑各种配置文件，只需在 CC Switch 的图形界面中添加 provider，即可一键切换。

## 配置 OrionisLi API

<Steps>
  <Step title="打开 CC Switch">
    启动 CC Switch 应用
  </Step>
  <Step title="添加自定义 Provider">
    点击「添加 Provider」，选择「自定义」
  </Step>
  <Step title="填写配置信息">
    - **名称**：`OrionisLi`（或你喜欢的名称）
    - **Base URL**：`https://sub.orionisli.cn`
    - **API Key**：你的 `sk-` 开头的密钥
  </Step>
  <Step title="选择要应用的工具">
    勾选你需要使用的工具（Claude Code、Codex、OpenClaw 等）
  </Step>
  <Step title="激活配置">
    点击「应用」，CC Switch 会自动写入各工具的配置文件
  </Step>
</Steps>

配置完成后，直接在终端中使用 `claude`、`codex`、`openclaw` 等命令即可，无需再手动设置环境变量。

|------|------|
