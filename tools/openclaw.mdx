<Tip>

</Tip>

## 方式一：CC Switch（推荐）

安装 CC Switch 后，在图形界面中添加 OrionisLi provider，选择应用到 OpenClaw 即可。详见 [CC Switch 文档](/tools/cc-switch)。

## 方式二：手动配置

OpenClaw 通过 `models.providers` 配置自定义 API 提供商。

### OpenAI 兼容模式（GPT 模型）

编辑 OpenClaw 配置文件：

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "orionisli/gpt-5.5" }
    }
  },
  "models": {
    "providers": {
      "orionisli": {
        "baseUrl": "https://sub.orionisli.cn/v1",
        "apiKey": "sk-你的密钥",
        "api": "openai-completions",
        "models": [
          {
            "id": "gpt-5.5",
            "name": "GPT-5.5",
            "contextWindow": 200000,
            "maxTokens": 8192
          },
          {
            "id": "gpt-5.4",
            "name": "GPT-5.4",
            "contextWindow": 200000,
            "maxTokens": 8192
          },
          {
            "id": "gpt-5.3-codex",
            "name": "GPT-5.3 Codex",
            "contextWindow": 200000,
            "maxTokens": 8192
          }
        ]
      }
    }
  }
}
```

### Claude 兼容模式

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "orionisli/claude-sonnet-4-6" }
    }
  },
  "models": {
    "providers": {
      "orionisli": {
        "baseUrl": "https://sub.orionisli.cn",
        "apiKey": "sk-你的密钥",
        "api": "anthropic-messages",
        "models": [
          {
            "id": "claude-sonnet-4-6",
            "name": "Claude Sonnet 4.6",
            "contextWindow": 200000,
            "maxTokens": 8192
          }
        ]
      }
    }
  }
}
```

## 使用环境变量管理密钥

建议使用环境变量而非硬编码 API Key：

```json
{
  "models": {
    "providers": {
      "orionisli": {
        "baseUrl": "https://sub.orionisli.cn/v1",
        "apiKey": "${ORIONISLI_API_KEY}",
        "api": "openai-completions",
        "models": [...]
      }
    }
  }
}
```

然后在 shell 中设置：

```bash
export ORIONISLI_API_KEY=sk-你的密钥
```

## 验证配置

```bash
openclaw doctor
```

此命令会检查配置文件格式、API 连通性等。

## 启动 OpenClaw

```bash
openclaw
```

## 常见问题

<AccordionGroup>
  <Accordion title="Provider 未识别">
    确认 `api` 字段正确：OpenAI 兼容用 `"openai-completions"`，Claude 兼容用 `"anthropic-messages"`。
  </Accordion>
  <Accordion title="模型列表为空">
    确认 `models` 数组中定义了至少一个模型，且 `id` 与 API 返回的模型 ID 一致。
  </Accordion>
  <Accordion title="连接超时">
    检查网络是否可以访问 `sub.orionisli.cn`。如有代理需求，配置 `HTTPS_PROXY` 环境变量。
  </Accordion>
</AccordionGroup>
